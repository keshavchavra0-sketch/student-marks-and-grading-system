## Overview of the Project
The Student Marks & Grading System is a simple Python-based console application developed to manage student marks and academic results.

The program allows the user to enter a student's name, roll number, and marks in five subjects — Maths, English, Hindi, Physics, and Chemistry. It automatically calculates the total marks and percentage, assigns a grade, and determines the student's PASS/FAIL status.

In addition to result calculation, the system provides basic student record management operations such as add, display, search, update, delete, and class summary.

The project is designed as a beginner-friendly Python application and was developed and tested in Google Colab.

## Features 

• Add Student: Enter a student's name, roll number, and marks. 
• Input Validation: Accept marks only from 0 to 100 and handle non-numeric input. 
• Automatic Calculation: Calculate total marks and percentage. 
• Grade Assignment: Assign a grade from A+ to F.
• Pass/Fail Result: A student passes only if they score at least 40 in every subject.
• Display Records: View all student records. 
• Search Student: Find a student using their roll number. 
• Update Student: Update a student's name and marks.
• Delete Student: Remove a student record.
• Class Summary: Show the number of students, pass/fail counts, class average, highest percentage, and top student's name. • Menu Validation: Show a message when an invalid menu option is entered.

 ## Steps to Install and Run the Project
  
1. The program displays a menu of available operations.
2. The user selects an option.
3. To add a student, the program asks for the student's name and roll number.
4. The program checks whether the roll number already exists.
5. The user enters marks for all five subjects.
6. The program validates each mark.
7. It calculates the total and percentage.
8. It assigns a grade and checks the pass/fail condition.
9. The student record is added to the program's list.
10. The user can then display, search, update, or delete records, or view the class summary.
11. The menu repeats until the user chooses Exit.
